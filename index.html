How I work

I build through agentic engineering. I brief Claude Code like a junior teammate, art-direct every draft against my own standards, and check everything before it ships.

I write HTML and CSS myself, so I design with the build in mind.

UVU's IT department trusts me to close and secure its campus computer labs at night, and the UVU Review promoted me from junior web developer to senior web developer after one school year, which took my scholarship from half tuition to full tuition. I keep a 3.58 GPA while working both jobs.
