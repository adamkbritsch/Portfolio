Introduction

DWDD 1720 deepened my CSS skills and introduced JavaScript. After learning basic HTML/CSS in DWDD 1600, this class pushed me into the “nitty-gritty” of styling and JS through projects that combined both.

What happened

We began by building a table of contents page—more design-heavy than the DWDD 1600 version—using the CSS skills we’d built. Next, we created a small JavaScript counter to track how many people boarded a train, learning basic functions in a site context.

We then made a practice portfolio site to link assignments and prep for a future, more complex portfolio. A later assignment was a JavaScript blackjack game that generated random numbers on button clicks; hitting the right range meant a win. Each project layered CSS and JS together.

Conclusion

This class grew my CSS and JavaScript fundamentals and expanded my HTML comfort. I learned to embed images from libraries and wire them up via JS files.
