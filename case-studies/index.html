How these pages are structured

Each case study page follows the same outline, making it easy to paste in process notes, artifacts, and outcomes without forcing a PDF download.

Overview + goals

Opening context, problem statement, and success criteria.

  • Eyebrow + headline for fast scanning
  • Tags for course, role, tools
  • CTA back to the hub and PDF

Process + artifacts

Space for research, wireframes, iterations, and comparisons without leaving the site.

  • Two-column layout for notes and highlights
  • Inline links to prototypes or repos
  • Room for visuals later on

Outcomes + next steps

Metrics, takeaways, and what to improve, kept alongside the rest of the portfolio.

  • Outcome bullets + callouts
  • Links back to course hubs
  • Downloadable PDF for offline review
