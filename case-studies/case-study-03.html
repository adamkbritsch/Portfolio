Introduction

About a year and a half ago I switched to Web Design and Development and took DWDD 1600. The curriculum clicked, but HTML was brand new. Knowing it was one of UVU’s most failed classes, I was determined to pass while learning the basics of HTML.

What happened

The class progressed weekly through practice sites built with HTML. Each tutorial increased difficulty, covering paragraphs, unordered lists, navigation, and headers. The gradual ramp let me absorb fundamentals at a manageable pace.

Midway through, CSS entered the picture. I experimented with colors, type, and sizing for nav and headers, realizing how styling paired with HTML transformed the experience. That shift turned initial motivation into genuine enjoyment.

Conclusion

DWDD 1600 taught me to read and write basic HTML/CSS and translate design ideas into code that serves user needs. It established the foundation for the career path I’m pursuing.
